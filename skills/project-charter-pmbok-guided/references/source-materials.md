# Source-Material Guidance

The `assets/` directory may contain locally available PMI publications and
industry research. The repository's `.gitignore` excludes PDF files, so these
documents are optional local references and are not part of the distributable
skill package.

## Usage Rules

- The skill must work without the local PDFs.
- Use a local source only when the user has authorized its use.
- Do not reproduce substantial source text. Summarize applicable principles in
  original language.
- Preserve citations or page references when the user requests traceability.
- Do not infer that local possession grants redistribution rights.
- Confirm applicable licenses before publishing or redistributing source files.

The tracked guidance, patterns, examples, and template contain everything
required for normal skill operation.
